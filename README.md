# ALX Backend Python Learning

A collection of Python exercises completed while building backend programming fundamentals.

## What this repository covers

- Python syntax and core concepts
- Control flow and conditional logic
- Functions and data structures
- Object-oriented programming
- Programming paradigms
- Problem-solving through small exercises

## Repository structure

| Directory | Focus |
|---|---|
| `python_introduction/` | Python fundamentals and introductory exercises |
| `control-flow/` | Conditions, loops, pattern drawing, and simple decision-making |
| `fns_and_dsa/` | Functions, data structures, and algorithmic thinking |
| `oop/` | Object-oriented programming concepts |
| `programming_paradigm/` | Programming approaches and paradigms |

## Running an exercise

Most files are standalone Python programs. From the repository root:

```bash
python path/to/file.py
```

Use `python3` instead of `python` on systems where Python 3 is not the default command.

## Learning approach

The goal of this repository is not just to collect solutions. The exercises are part of a progression toward understanding how to break a problem into inputs, processing, decisions, outputs, and reusable logic.

The original coursework is intentionally preserved so the repository reflects the learning process.
